# ObraAI · Plataforma de Control y Supervisión de Obra

Aplicación web (un solo archivo `index.html`) para el control de avance de obra con acceso por código personal o QR, sincronizada con Supabase.

- Abrir: `https://<usuario>.github.io/<repositorio>/`
- Ingreso: código personal entregado por el administrador o QR de la credencial.
- Prototipo académico (Diplomado en IA). La base de datos es un entorno de pruebas.
